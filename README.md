# Tikhome — مشروع كامل يعمل

تطبيق ويب للجوال (فيديو/صور بنمط TikTok + خريطة بدبابيس الدور والمدخل + تواصل واتساب) مع خادم وقاعدة بيانات ولوحة تحكم. بدون أي مكتبات خارجية.

## التشغيل
المتطلب: Node.js 22.5 أو أحدث.

    npm start            # أو: node --disable-warning=ExperimentalWarning server.js
    npm test             # اختبار تكامل (15 فحصاً)

ثم افتح http://localhost:3000 للتطبيق و http://localhost:3000/admin للوحة التحكم.

## حساب المدير
عند أول تشغيل يُنشأ مدير برقم `ADMIN_PHONE` (الافتراضي 0500000000). كلمة السر من `ADMIN_PASSWORD`، وإن لم تُحدَّد تُولَّد عشوائياً وتُكتب في `data/FIRST_ADMIN.txt`. غيّرها فور الدخول واحذف الملف.

## متغيرات البيئة
PORT · DATA_DIR (قاعدة البيانات والملفات المرفوعة) · ADMIN_PHONE · ADMIN_PASSWORD · COOKIE_SECURE=1 (عند التشغيل خلف HTTPS)

## ما تتحكم به من لوحة المدير
مراجعة الإعلانات (موافقة/رفض بسبب/إيقاف/تمييز/حذف) · المستخدمون (توثيق/إيقاف/ترقية) · البلاغات · الباقات والاشتراكات · الإعدادات (المراجعة قبل النشر، التسجيل، حدود الفيديو والصور، رسالة واتساب) · سجل العمليات · الإحصائيات.

## الاستضافة
شغّله على خادم (VPS) خلف Nginx/Caddy مع شهادة HTTPS، وفعّل COOKIE_SECURE=1، واحفظ مجلد DATA_DIR ضمن النسخ الاحتياطي.

## حدود معروفة
- لا يوجد تكامل مع نفاذ: التوثيق يطلبه المستخدم ويعتمده المدير يدوياً.
- لا توجد بوابة دفع: تُفعَّل الاشتراكات يدوياً بعد استلام المبلغ.
- التواصل عبر رابط wa.me وليس WhatsApp Business API.
- الخريطة تحمّل Leaflet وبلاطات OpenStreetMap من الإنترنت.
- الرفع يُعالج في الذاكرة (مناسب للمرحلة الأولى؛ للأحمال الكبيرة انقل الملفات إلى تخزين سحابي).
- نظامياً: كل إعلان يحتاج رقم ترخيص إعلان من الهيئة العامة للعقار، والمنصة نفسها تحتاج ترخيصاً. استشر مستشاراً قانونياً قبل الإطلاق.
